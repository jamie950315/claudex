# Claudex 1.3.25

Development build of 2026-10-11; not yet a published release. App **1.3.25**
bundles Claude Mod **0.8.22** (unchanged). These notes summarize changes since
1.3.24.

## A provider switch no longer pauses a conversation with a kept snapshot

Switching the Codex provider with an account tool rewrites the provider label
(`model_provider`) in the first line of every Codex rollout. A conversation
whose earlier Codex snapshot is kept because other threads depend on it
verified that snapshot by its exact bytes, so it paused with "Dependency
anchor saved transcript bytes changed" for as long as the other provider was
selected, and recovered when the label was switched back.

The label is not conversation content. The snapshot is now also identified
without it: the same file under another provider label is the same snapshot.
Every other value of the header and every byte after it are compared as
before, and the stored size may differ only by the length of the label.

A snapshot kept by an earlier version gains this identity the next time its
conversation synchronizes while the file still has its original bytes. Until
then it keeps the exact check.

## Verification

- Automated tests, without model inference.
- The one kept snapshot on the development Mac was verified under its current
  label. The label-switched case is covered by synthetic tests only; it was
  not exercised against a real provider switch.
