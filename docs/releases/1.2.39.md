# Claudex 1.2.39

Development build of 2026-10-09; not yet a published release. App **1.2.39**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged from App
1.2.27. App and Mod versions are separate. These notes summarize changes since
1.2.38.

## Historical frontend binding forms

- Recognize the observed LocalSessions initializer with one discarded native
  host read before the exact optional API access. Calls, foreign hosts and extra
  expressions remain unsupported.
- Recognize older folder keys using the exact local-or-CLI type helper. Require
  one complete key/grouping/native proof across competing role candidates;
  changed, asynchronous or shadowed helpers remain refused.
- Recognize reversed strict undefined comparisons for the optional native fork
  capability and nested async cold catalogue queries with unchanged cwd/session
  routing. Preserve enclosing lexical guards, native errors and result checks.
- Distinguish the observed August shortcut-help capability reads from the
  uniquely proven native fork action. Competing actual actions remain refused.
- Inspect the observed public React.memo component wrapper without changing
  its call or comparator semantics. Preserve exact owner identity, retained
  native send and attached-client proofs, including same-name block-local
  variables that do not access the outer session ref.
- Historical backtests can expose unsupported layouts: ambiguous wake modules,
  imperative forwarding wrappers and missing archival dependencies do not become
  activation proof. Static source/installation checks do not certify historical
  native UI behavior or arbitrary future frontend semantics.

Resource limits, owner eviction, native transport, inference permissions and the
bundled Mod are unchanged.
