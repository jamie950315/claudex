# Claudex 1.3.26

Development build of 2026-10-11; not yet a published release. App **1.3.26**
bundles Claude Mod **0.8.22** (unchanged). These notes summarize changes since
1.3.25.

## A `/compact` that names a row Claude never saved no longer pauses

After `/compact`, Claude records which row the compaction follows. Claude Code
2.1.295 was observed naming a row that it never wrote to the transcript, right
after a completed turn. Claudex read that as earlier history being missing and
paused the conversation with "compaction does not continue its complete
persisted prefix", although every message was still in the file.

Earlier history is now considered missing only when nothing precedes the
compaction, or when the named row is in the file but is not the last one
before it. Claudex's own context reset keeps naming its exact row.

## Verification

- Automated tests, without model inference.
- All 537 local Claude transcripts were decoded by the previous and the changed
  reader: the one paused transcript now decodes and the other 536 give
  identical messages.
