# Claudex 1.2.40

Development build of 2026-10-10; not yet a published release. App **1.2.40**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged. App and Mod
versions are separate. These notes summarize changes since 1.2.39.

## Transient frontend-cache checks

- Show the existing single immediate rediscovery as a normal Desktop integration
  check, rather than asking the user to resolve a failure before that check ends.
  A second transient failure, missing recovery evidence, access denial or mixed
  permanent refusal remains explicit; no additional retry or timer is added.
- Preserve genuine map/history errors and deferred maps while the renderer checks.
  A checking resource is not ready and does not certify loaded-renderer reception.
- Retain one bounded lastFailure phase/code/time for the current maintenance
  process, with recoveredAt after a coherent pass. Diagnostics exclude native
  error text, paths and cache keys. Persistent thrown failures display the fixed
  phase/code instead of only the generic refusal message.
- Localize the checking title and explanation in all nine app languages.

Historical source backtests do not eliminate races with a live cache writer.
This change does not expand frontend compatibility, restart Claude, start native
owners or model inference, or weaken installer and journal guards.
