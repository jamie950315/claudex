# Claudex 2.0.3

Released on 2026-10-18. App **2.0.3** bundles Claude Mod **0.8.61**.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v2.0.3).
App and Mod versions are separate. These notes summarize changes since 2.0.2
(Mod 0.8.53).

## Conversation continuity across native updates

- **Dialogue-based progress:** synchronization checkpoints now also record the
  dialogue: message roles and order, exact user/assistant text and images, and
  tool, reasoning and inert event identities. A native update that re-projects
  tool or event payloads no longer pauses an otherwise unchanged conversation.
  Edited messages, missing messages and changed identities still conflict.
  Existing checkpoints gain the dialogue proof only after an exact read.
- **Late native items:** match an API item by its identity and kind rather than
  a vendor-specific payload projection. Writes, archival, retirement, relocation
  and the tail written during a handoff retain their exact-byte proofs.
- **Codex 0.163 compatibility:** authenticate checkpoints saved before Codex
  added null `model` and `reasoningEffort` fields to sub-agent activity. Non-null
  values are preserved. Raw provenance accepts absolute per-turn working
  directories and a verified project move's original creation directory without
  weakening thread or session identity checks.

## Reliable inbox reads and visible failures

- Synchronization inbox reads and writes use the shared stable-file storage
  implementation. A reader overlapping an atomic replacement rereads while
  retaining exact file-identity checks; concurrent publishers retain the
  existing ownership and lock proofs.
- Transport failures, malformed sources and unfinished transactions remain
  visible as blocked conversations instead of being hidden as ordinary waits.
- Deferred or failed native folder publication stays dirty until a later watcher
  pass publishes a ready result.

## Packaging

- Successful app builds remove their private staging directory after publishing
  the bundle and archive. Failed builds preserve staging for inspection.
- Mod 0.8.61 packages this release's native engine and matching loaded-version
  observer. App startup maintains it through the normal native plugin manager;
  existing sessions may retain an older loaded Mod until their normal lifecycle
  loads the update.

## Verification

- The standard Rust workspace suite passed 376 tests with zero failures
  (six opt-in/internal tests ignored), and all seven Node entry-point checks
  passed. The affected JavaScript history/provenance reference suites passed
  all 131 tests.
- The packaged Mod 0.8.61 passed official strict validation and all 26 native
  kit tests on Claude Code 2.1.302. A separate isolated integration test verified
  that its staged native helper reads the real Unix RPC broker after its source
  executable copy is removed.
- The release ZIP was extracted and its complete app signature verified with
  `codesign --verify --deep --strict`. Both the bundle and embedded engine report
  2.0.3. No installed app replacement, native restart or model inference was
  performed for this release.

## Distribution

Apple Silicon, macOS 13 or later. The app has an Apple Development signature
and is not notarized. `Claudex-v2.0.3-macOS-arm64.zip` and `SHA256SUMS` are
available on the release page.
