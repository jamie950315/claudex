# Claudex 1.4.3

Released on 2026-10-12. App **1.4.3** bundles Claude Mod **0.8.24**, unchanged.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v1.4.3).
App and Mod versions are separate. These notes summarize changes since the
last published release, 1.4.2.

## An edited Codex message no longer pauses a conversation with a late command

- Editing and resending a message makes Codex continue the thread in a new
  rollout file. From then on Codex reports a command that finished after its
  own turn had closed, such as a local server left running, inside the turn
  that started it. Claudex had saved it where it finished and could prove
  that only from the rollout file in use, so the conversation paused with
  "Codex native history diverged before the verified canonical checkpoint".
- The proof now also reads the earlier rollout files the new one declares it
  continues, limited to the rows each one contributes. The saved history is
  matched as before; nothing is rebased or rewritten. A forked thread's
  inherited commands, and a real change to earlier history, still pause.

Found in one real conversation, which matches its saved checkpoint again with
this build (3,421 saved messages; one command moved by 211 positions). Also
covered by a synthetic rollover test.

## Distribution

Apple Silicon, macOS 13 or later. The app has a development signature and is
not notarized.
