# Claudex 2.0.2

Released on 2026-10-17. App **2.0.2** bundles Claude Mod **0.8.53**.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v2.0.2).
App and Mod versions are separate. These notes summarize changes since 2.0.1
(Mod 0.8.50).

## Native project folders, owner wake and Local handoff

- **Owner metadata read bound:** the Claude owner writer keeps the last appended
  packet in its metadata for exact duplicate recovery, so an owner file may grow
  up to the 64 MiB packet bound. Folder projection, owner wake and Local handoff
  read the same file with a 2 MiB limit, so a conversation whose last append
  carried images or long text blocked **Native project folders** with
  `File exceeds its read size limit.` All owner-metadata readers now share the
  writer's bound (`OWNER_STATE_LIMIT`). The Local handoff manifest and the
  generated folder map keep their tighter write bounds, and every identity,
  ownership and single-link proof is unchanged.

## Background synchronization performance

- **Faster startup and reconnect sweep:** the background history sweep
  coalesces diagnostic progress updates to two-second intervals and deduplicates
  in-memory Desktop state and archive reads within a pass.
- **Leaner rollout provenance reads:** Codex rollout provenance scanning keeps
  row bytes and parsed lines only when a protected digest or prefix guard needs
  them, and measures the remaining bounded tail without buffering it. Compressed
  `.jsonl.zst` rollout length is read from one verified decompression.

## Verification

- **Automated suite:** the Rust workspace tests (`cargo test --locked
  --workspace`) and the Node entry-point compatibility tests
  (`npm run test:entrypoints`) passed with zero failures. A new regression test
  publishes folders and activates an owner whose metadata exceeds 3 MiB. The
  staged Mod `0.8.53` passed official strict validation
  (`claude plugin validate --strict`) and the native Mod kit tests.
- **Live installation:** on the installed macOS service, the previously
  refused 3.0 MB owner no longer blocks folder projection: the watcher reports
  `folderProjection.state: "ready"` with 257 entries, the initial sweep
  completed for all 483 conversations with `blockedConversationCount: 0`, and
  Local handoff reports `ready`. Services were drained and resumed through the
  normal `app stop` / `app startup` path without restarting native apps.

Apple Silicon, macOS 13 or later. The app has an Apple Development signature
and is not notarized. `Claudex-v2.0.2-macOS-arm64.zip` and `SHA256SUMS` are
available on the release page.
