# Claudex 1.2.37

Development build of 2026-10-09; not yet a published release. App **1.2.37**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged from App
1.2.27. App and Mod versions are separate. These notes summarize changes since
1.2.36.

## Owner wake recognizes the observed retained-ref Code frontend

- Early September Code builds retain the selected session in a React ref rather
  than a getter callback. Require its public `useRef` import, exact selection
  seed, sole `useEffect` mirror and native send reader before installation.
- Ref escapes, changed seeds/dependencies, additional writers, lexical shadows
  and ambiguous targets remain refused. Native send and all existing backend
  activation guards are preserved; no additional owner or model work is started.
- Keep bounded graph discovery, syntax validation and independent original-cache
  journals. Historical vendor source is tested in isolated caches; this does not
  certify historical native UI behavior or arbitrary future frontend semantics.
