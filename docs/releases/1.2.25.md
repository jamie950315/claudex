# Claudex 1.2.25

Released on 2026-10-06. App **1.2.25** bundles Claude Mod **0.8.15**.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v1.2.25).
The bundled Mod payload is unchanged from App 1.2.24. App and Mod versions are
separate. These notes summarize changes since the last published release, 1.2.24.

## An unrecognized failure holds one conversation instead of stopping the watcher

- The watcher held a conversation only when its error matched a fixed list of
  messages. Any other failure while reading or planning one conversation ended
  the watcher for every conversation, and the supervisor restarted it into the
  same failure. Messages that did this included a Codex history diverging before
  its saved checkpoint, a malformed transcript record, the Codex page and item
  limits, an external user image and a timed-out Codex request.
- Such a failure now holds only that conversation and reports its own reason as
  blocked. It is not retried and is never reported as synchronized. This applies
  only when no pending transaction exists, the ledger is readable and the shared
  Codex backend still answers.
- Failed recovery of a pending transaction, an unreadable ledger, a shutdown
  request and failures outside a single conversation still stop the worker. An
  unavailable backend is still reported as waiting, not as a conversation hold.

## Larger optional history budget

- `nativeHistoryMaxBytes` in the private root's `config.json` now accepts up to
  **268435456** bytes (256 MiB) instead of 67108864. The 16 MiB default, the
  256-page, 25,000-item and 64 MiB WebSocket-frame limits are unchanged.
- On the Mac used for verification, four tracked Codex conversations already used
  54–73% of the previous 64 MiB maximum, mostly display-only Computer Use
  screenshots in conversations enrolled before those screenshots were omitted.
- The watcher holds a history in memory while reading it, so a larger budget
  raises its peak memory use for large conversations. Raw and converted
  histories must both fit the configured budget; exceeding it still holds that
  conversation without truncation.

Collaboration and cache warming are unchanged.

## Verification

The complete source gate passed **1,982 tests**, with zero failures and 23
explicit opt-in native skips. The release ZIP was extracted; all **139 packaged
engine/Mod files** and **nine locale catalogs** matched the source, and strict
deep signature verification passed. Publication does not start new model work
or interrupt native sessions.

A synthetic 75 MiB Codex history is read within a 256 MiB budget and still
refused by a 64 MiB one. On the Mac used for verification, the installed 1.2.25
app with the budget set to 256 MiB completed verification of **407/407
conversations** with zero synchronization blocks. No real conversation there
exceeds 64 MiB yet, and no unrecognized failure occurred after installation, so
both changes rest on the automated tests rather than a live occurrence. This is
an installed-Mac check, not a clean-machine or blanket certification of every
native version.

## Updating

Replace the app through a normal idle shutdown and reopen it. Existing Claude
Code sessions keep their loaded Mod; this release does not change it.
Installation does not force-close native work, replay uncertain input or trust
Codex hooks automatically. Change `nativeHistoryMaxBytes` only while the app is
stopped.

## Distribution

The download targets **Apple Silicon Macs running macOS 13 or later** and bundles
portable Node/npm and production dependencies. Existing compatible Codex/ChatGPT
and Claude desktop apps, native sign-ins, permissions and native hook trust remain
required. Vendor desktop apps, credentials, private state and transcripts are not
bundled.

This build is **Apple Development signed, not Developer ID signed or notarized**.
It does not establish frictionless Gatekeeper acceptance on every other Mac.
Do not disable OS verification to conceal that limitation.
