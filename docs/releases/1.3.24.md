# Claudex 1.3.24

Development build of 2026-10-11; not yet a published release. App **1.3.24**
bundles Claude Mod **0.8.22** (unchanged). These notes summarize changes since
1.3.23.

## Claude transcripts are read the same way: real problems only

1.3.23 changed the readers of Codex data to refuse real problems instead of
unfamiliar forms. The readers of Claude transcripts now follow the same rule.

- **Branches.** Claude keeps every branch of a conversation in its file. Only
  three exact shapes were read (a rewind, the parallel-tool graph, a streamed
  wave) and any other fork paused the conversation as "nonlinear". Every fork
  is read now, the way the Claude app itself resumes: the conversation is the
  branch that ends at the last message. A branch a new prompt or a regenerated
  reply replaced is left out; tool results and the other blocks of the same
  response are kept where they are. Nothing of the active conversation is
  dropped.
- **Compaction.** After `/compact` every earlier message is still in the
  file. How Claude flags the summary or describes the segment it preserved is
  no longer compared, so a release that changes that record does not pause the
  conversation. What is checked is whether the earlier history is really
  there, whether the summary is readable, and whether it belongs to the same
  session and directory.

Still refused: a message whose parent is missing, a tool call without its
result, a result without its call, a replaced branch that held turns already
synchronized, and earlier history missing before a compaction. Claudex's own
context reset, which is a write, keeps its exact proof.

Checked by decoding all 537 local Claude transcripts before and after: every
one decodes to exactly the same messages.
