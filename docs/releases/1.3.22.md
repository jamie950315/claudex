# Claudex 1.3.22

Development build of 2026-10-11; not yet a published release. App **1.3.22**
bundles Claude Mod **0.8.22** (unchanged). These notes summarize changes since
1.3.21.

## The empty-turn proof no longer lists every context form

A review of the proofs against all local histories (1,560 Codex rollouts and
537 Claude transcripts) found the remaining exact lists of the same kind as
the trigger list removed in 1.3.21. All were in the proof for a Codex turn
with no reply, and none had paused a conversation yet:

- **Native state snapshots.** Only one in five observed full `world_state`
  records had exactly the listed fields, and only two of some sixty observed
  partial forms were accepted. Any state fields are accepted now.
- **Runtime context messages.** Twenty observed kinds of developer-role
  context (plugin and app instructions, a model switch notice, image resize
  notices and others) were unknown to the list. The developer role is
  accepted whatever its kind. The user role keeps its exact list, because
  that is where authored input appears.
- **Settings and goal changes.** A `thread_settings_applied` or
  `thread_goal_updated` event inside the turn, a goal change after it, and a
  settings record without a thread ID (written by older runtimes) are
  accepted.

What makes a turn nonempty is unchanged: any assistant, tool, reasoning or
token record, any authored user input, and identities or times that differ
from what Codex reports.

Checked over the local rollouts in both directions: all 35 real empty turns
are accepted, and of 2,341 real turns with activity presented as empty none
is accepted. The other proofs (late command results, Claude transcripts)
accepted every local history as they were.
