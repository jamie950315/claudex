# Claudex 1.0.0

Claudex connects existing Codex and Claude installations for completed-turn
history synchronization, explicit cross-model work, and cooperative native-chat
coordination. This version includes the unified macOS application and app icon.

## Included

- Automatic setup, native account sign-in guidance, bundled Node.js runtime,
  and registration of the collaboration MCP connection.
- Hook/event-driven synchronization instead of continuous two-second history
  polling, with preserved originals and guarded complete-turn boundaries.
- One icon-only menu bar item, responsive combined status/setup window,
  automatic window sizing, and nine interface languages.
- Bidirectional delegation and same-task handoff, provider-specific model and
  reasoning-effort defaults, per-task overrides, and explicit result states.
- Up to 64 concurrent workers and delegation depth three, with overlapping
  read/write scopes serialized instead of concurrent conflicting edits.
- Project-root defaults, additional read-only references and writable directories,
  inherited or narrowed child scopes, and native permission enforcement.
- Cooperative messages to exact existing hooked native chats, title search,
  ambiguity handling, and separate queued/offered/acknowledged receipts.
- Quit stops owned background services safely; reopening resumes verified
  installed services without deleting conversation data or preferences.

## Requirements and limits

The graphical build targets Apple Silicon Macs running macOS 13 or later.
Codex/ChatGPT and Claude Desktop must already be installed. Native account access,
required sign-ins, permissions and hook trust remain the user's responsibility.
Existing native clients may need to refresh their MCP tool connections.

The current macOS build uses an Apple Development signature. It is **not
Developer ID signed or notarized**, and clean-user/clean-machine installation
acceptance has not been completed. Version 1.0.0 is a product version, not a
claim that those distribution requirements or every future vendor version have
been validated. Do not disable macOS security controls to hide this limitation.

Native-chat messages wait for a usable hook boundary and do not wake an entirely
idle conversation. Acknowledgement proves receipt, not execution of a requested
action. Title search covers registered chats with readable native metadata;
duplicates require disambiguation. No replacement chat or external transcript
writer is used for message delivery.

Model calls consume native account allowances. Parallel limits are ceilings,
not a resource or cost guarantee; 64 simultaneous native executions have not
been load-certified. Native policies may cap requested reasoning effort.
Unknown/uncertain work is never silently replayed. Read the [app guide](../app.md),
[collaboration protocol](../collaboration.md), and
[synchronization boundaries](../synchronization.md) before deployment.
