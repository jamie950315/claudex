# Claudex 1.2.36

Development build of 2026-10-09; not yet a published release. App **1.2.36**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged from App
1.2.27. App and Mod versions are separate. These notes summarize changes since
1.2.35.

## Owner wake adapts to more frontend compiler and chunk changes

- Search shortlisted Code modules and components by their complete semantic
  relationships, rather than selecting a neighbouring lookalike by markers.
- Follow callback aliases, block-return readers, function/arrow component forms
  and named re-exports. Resolve memo helper definitions, including variadic
  stores, to prove the returned callback instead of guessing its position.
- Bound import tracing to eight modules and callback resolution to twelve
  steps. Ambiguity, cycles, missing dependencies and unknown helper semantics
  still refuse installation; native source, original caches and journals remain.
- Preserve the exact selection/native-send reference, attached stdio client and
  backend activation guards. Owner eviction and the UI are unchanged; no
  additional owner is kept running and no model request is submitted.
- Reuse compact binding provenance from the graph's existing syntax pass and
  parse exact helper bodies on demand, avoiding retained dependency ASTs.
- Discovery is best effort for future builds. A new cache installation still
  needs an idle Claude restart before its loaded adapter can be verified.
