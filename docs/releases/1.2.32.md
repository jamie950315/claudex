# Claudex 1.2.32

Development build of 2026-10-09; not yet a published release. App **1.2.32**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged from App
1.2.27. App and Mod versions are separate. These notes summarize changes since
1.2.31.

## Folder placement and owner wake recognize the 2026-10-09 Claude frontend

- The frontend Claude Desktop fetched on 2026-10-09 writes its compiler memo
  through helper calls instead of spelling out each cache slot. Two adapters
  no longer recognized their targets: the folder adapter was skipped with
  `folder consumer dependencies missing or ambiguous`, and owner wake with
  `Code retained send callback missing or ambiguous`.
- Without owner wake, opening a synchronized conversation whose Claude owner
  had been closed while idle did not start that owner again. Claude Desktop
  showed the conversation as `Remote Control disconnected`.
- Both adapters now accept the helper form. The owner-wake callback is the one
  function, or nested store call, among a store call's arguments; the folder
  consumer's grouping and key guards are checked for the same dependencies,
  store index and result slot as before. Earlier builds keep their existing
  checks.

Static acceptance covers the 19 frontend builds cached on the reviewed machine:
all four adapters install on every build, and automatic re-application from the
previous build to the newest one, repeated installation and restoration pass in
an isolated copy. The script's overall result stays negative only for two
obsolete owner-wake pins it reports by design.

This is not live acceptance. Newly installed resources take effect after a
normal idle Claude restart. A restart can also fetch a newer frontend, which
the adapters then have to match again.
