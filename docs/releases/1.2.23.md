# Claudex 1.2.23

Released on 2026-10-06. App **1.2.23** bundles Claude Mod **0.8.15**.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v1.2.23).
The bundled Mod payload is unchanged from App 1.2.22. App and Mod versions are
separate. These notes summarize changes since the last published release, 1.2.22.

## Mod installation check

- Claude Code 2.1.288 writes `claude-code-tools` and `claude-code-mcp` type
  declarations beside the existing `claude-code` declarations in an installed
  Mod's cache. App 1.2.22 treated them as unlisted files, reported an intact
  Mod 0.8.15 installation as needing attention, and refused Install / Update
  because that action runs the same check first.
- The equal-version payload check now accepts exactly these two additional
  native-generated declaration paths. Every shipping file is still compared
  with the bundled payload, and any other unlisted file is still reported as a
  content mismatch. No installed file, setting or journal is rewritten.

Synchronization, collaboration and cache warming are unchanged.

## Verification

The complete source gate passed **1,975 tests**, with zero failures and 23
explicit opt-in native skips. The release ZIP was extracted; all **139 packaged
engine/Mod files** and **nine locale catalogs** matched the source, and strict
deep signature verification passed. Publication does not start new model work
or interrupt native sessions.

On the Mac that showed the failure, the installed 1.2.23 app reports the
unchanged Mod 0.8.15 installation as current with manager 2.1.288, and completed
verification of **401/401 conversations** with zero synchronization blocks.
This is an installed-Mac check, not a clean-machine or blanket certification of
every native version.

## Updating

Replace the app through a normal idle shutdown and reopen it. Existing Claude
Code sessions keep their loaded Mod; this release does not change it.
Installation does not force-close native work, replay uncertain input or trust
Codex hooks automatically.

## Distribution

The download targets **Apple Silicon Macs running macOS 13 or later** and bundles
portable Node/npm and production dependencies. Existing compatible Codex/ChatGPT
and Claude desktop apps, native sign-ins, permissions and native hook trust remain
required. Vendor desktop apps, credentials, private state and transcripts are not
bundled.

This build is **Apple Development signed, not Developer ID signed or notarized**.
It does not establish frictionless Gatekeeper acceptance on every other Mac.
Do not disable OS verification to conceal that limitation.
