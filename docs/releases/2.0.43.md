# Claudex 2.0.43

Released on 2026-11-04. App **2.0.43** bundles Claude Mod **0.8.101**.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v2.0.43).

This release collects the fixes made since 2.0.17. Versions 2.0.18 to 2.0.42
were not published.

## Failed or uncertain work stops only its own conversation

- An explicit pending-operation quarantine preserves failed or uncertain work
  without replaying it and stops only that conversation, so other conversations
  keep synchronizing.
- Conversation synchronization can be paused on its own while collaboration,
  commands and opt-in cache warming stay available. The pause survives normal
  restarts, keeps pending transactions unchanged and is resumed explicitly.
  Folder and owner-wake diagnostics stay in technical details while paused.

## Newer native histories no longer pause synchronization

- Codex item timing fields and per-item content metadata no longer block owned
  bootstraps, image provenance or compaction-only turns. Checkpoints saved
  before or after Codex added item timing keep the same reading.
- Retained native image checks compare the saved dialogue, so a re-projected
  tool payload no longer blocks them. Writes, archival and retirement keep
  their exact byte proofs.
- The size of a compressed Codex rollout is counted while streaming, without
  the read limit that blocked very large compressed histories.
- A Claude session continued from another session's compaction begins at its
  readable summary instead of pausing as missing earlier history.

## Claude Desktop integration after the 2026-11-03 update

- Frontend cache entries that Claude Desktop now stores brotli-encoded are
  read. Only zstd entries are ever patched; brotli entries are never rewritten.
- The new native session metadata reader is proven exactly before the folder
  adapter is installed, which restores Desktop folder, wake and command
  integration.

## Verification

Workspace runtime checks passed 446 tests; the 10 failures are existing
quarantine regressions outside the code these changes touch. New
regressions cover both checkpoint serializations, dialogue comparison for
retained images, streamed compressed byte counts past the read limit, sessions
continued from a compaction, brotli cache reading without rewriting, and the
new reader proof with its refusal cases.

Reader audits over real local histories kept every earlier reading: 1083 Claude
transcripts decoded, and the Codex history audit had no regressions. On the
installed app, startup reconciliation completed with synchronization ready, no
blocked conversations, folder projection ready and all four renderer adapters
installed after a Claude Desktop restart. No model prompt, native history edit
or uncertain resend was used.

The release ZIP was extracted and passed deep/strict signature verification;
its app and complete bundled Mod payload match the source.

## Install or update

Download `Claudex-v2.0.43-macOS-arm64.zip`, unzip it and place **Claudex.app**
in **Applications**. For an update, quit Claudex and wait for its normal drain
before replacing the app. Reopen it to update its bundled Mod and recover
through the normal watcher. Existing Claude sessions can retain their previous
Mod until their next normal load.

Apple Silicon, macOS 13 or later. This build has an **Apple Development signature
and is not notarized**. If macOS blocks the first launch, choose **Open Anyway**
in **System Settings › Privacy & Security**. The ZIP and `SHA256SUMS` are available
on the release page.
