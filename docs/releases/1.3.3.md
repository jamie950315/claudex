# Claudex 1.3.3

Development build of 2026-10-10; not yet a published release. App **1.3.3**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged. These notes
summarize changes since 1.3.2.

## The automatic Claude restart window is one minute

- The one-time restart after a frontend update now applies only while Claude
  Desktop is at most one minute old, instead of two. In the one observed
  update every adapter was installed about 28 seconds after the start.
- A shorter window makes it less likely that a draft is being typed when the
  restart happens. When the adapters are not all installed within that minute,
  nothing is restarted and the resource stays `restart-required`, as before.
