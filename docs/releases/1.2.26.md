# Claudex 1.2.26

Released on 2026-10-06. App **1.2.26** bundles Claude Mod **0.8.15**.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v1.2.26).
The bundled Mod payload is unchanged from App 1.2.25. App and Mod versions are
separate. These notes summarize changes since the last published release, 1.2.25.

## Fix for a raised history budget in 1.2.25

- 1.2.25 accepted `nativeHistoryMaxBytes` above 67108864 but also passed that
  value as the size limit of the context packet that carries a delivery. The
  packet encoder refuses any limit above its unchanged 64 MiB cap, so with a
  larger setting every delivery failed with `invalid native packet byte limit`.
  A transaction already prepared could not be recovered, the watcher exited and
  its supervisor restarted it into the same failure until the setting was
  lowered again. Installations that kept the setting at or below 67108864 were
  not affected.
- The packet limit is now the smaller of the configured budget and the 64 MiB
  packet cap. Reading a history larger than 64 MiB therefore works with a raised
  budget, while a single delivery packet still cannot exceed 64 MiB.

If you run 1.2.25 with `nativeHistoryMaxBytes` above 67108864, update to this
release or lower the setting to 67108864 while the app is stopped.

Other synchronization behavior, collaboration and cache warming are unchanged.

## Verification

The complete source gate passed **1,983 tests**, with zero failures and 23
explicit opt-in native skips, including a delivery encoded under a 256 MiB
budget. The whole suite also passes with the runtime temporarily defaulting to a
256 MiB budget, apart from the one test that pins the 16 MiB default. The release
ZIP was extracted; all **139 packaged engine/Mod files** and **nine locale
catalogs** matched the source, and strict deep signature verification passed.
Publication does not start new model work or interrupt native sessions.

On the Mac where the failure occurred, the 1.2.25 watcher restarted eight times
over about seven minutes until the setting was restored; the prepared
transaction then recovered without resending anything. With the installed
1.2.26 engine, the same real conversation's packet encodes under a 256 MiB
budget and fails with the 1.2.25 behavior. The installed 1.2.26 app with the
budget set to 256 MiB completed verification of **407/407 conversations** with
zero restarts and zero synchronization blocks. A complete real delivery under
the raised budget had not yet occurred when these notes were written. This is an
installed-Mac check, not a clean-machine or blanket certification of every
native version.

## Updating

Replace the app through a normal idle shutdown and reopen it. Existing Claude
Code sessions keep their loaded Mod; this release does not change it.
Installation does not force-close native work, replay uncertain input or trust
Codex hooks automatically. Change `nativeHistoryMaxBytes` only while the app is
stopped.

## Distribution

The download targets **Apple Silicon Macs running macOS 13 or later** and bundles
portable Node/npm and production dependencies. Existing compatible Codex/ChatGPT
and Claude desktop apps, native sign-ins, permissions and native hook trust remain
required. Vendor desktop apps, credentials, private state and transcripts are not
bundled.

This build is **Apple Development signed, not Developer ID signed or notarized**.
It does not establish frictionless Gatekeeper acceptance on every other Mac.
Do not disable OS verification to conceal that limitation.

The release includes `Claudex-v1.2.26-macOS-arm64.zip` and `SHA256SUMS`.
