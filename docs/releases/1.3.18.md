# Claudex 1.3.18

Development build of 2026-10-10; not yet a published release. App **1.3.18**
bundles Claude Mod **0.8.20**. These notes summarize changes since 1.3.17.

## More in the app's Cache settings window

- **Startup cache TTL** (Claude Code only): this process only, remember the
  last TTL, or a fixed 1h or 5m. It was only in the Mod pane; it is now saved
  in Claudex so the app can show and change it without an open session. It is
  applied when a new Claude Code session starts and never enables warming.
- A preference saved by an earlier Mod stays in use until one is saved in
  Claudex; the window says when that is the case.
- **Conversations being kept warm** lists the running warm-ups of Claude Code
  and Codex with their folder, requests used, end time and TTL, each with a
  Stop button. Stop ends that one warm-up; the conversation is untouched.
- Each section is labeled with the apps it applies to.
- The TTL of a session that is already running still changes only inside that
  session (`/claudex:warm on 5m` or `1h`, or the Mod pane).

## Fixes

- The count of conversations being kept warm no longer includes warm-ups that
  already reached their end time.

Checked with injected data, the native validator and the native test kit, and
by opening the window in the installed app.
