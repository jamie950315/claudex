# Claudex 1.3.9

Development build of 2026-10-10; not yet a published release. App **1.3.9**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged. These notes
summarize changes since 1.3.8.

## Images sent just before a Codex rollover no longer pause the conversation

- Codex continues a long conversation in a new rollout file. Turns written
  after the last synchronization stay in the previous file, which Claudex reads
  as the saved path. An image in such a turn was refused with "Retained native
  image evidence cannot supply a new message outside its verified checkpoint",
  and the conversation stayed paused.
- The image is now accepted when the new rollout's own `history_base` reference
  to that exact file covers the turn and a second read bounded to that prefix
  returns the same bytes. Without that declared reference, or for a turn
  outside its prefix, the refusal is unchanged.

Checked with synthetic rollouts and on the affected conversation of this Mac.
