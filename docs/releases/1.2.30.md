# Claudex 1.2.30

Development build of 2026-10-09; not yet a published release. App **1.2.30**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged from App
1.2.27. App and Mod versions are separate. These notes summarize changes since
1.2.29.

## A conversation that ends with a local command is no longer "still running"

- A Claude conversation whose last action was a native local command, such as
  `/compact`, `/model` or a plugin pane command, was treated as an unfinished
  turn. Claudex reported `Claude turn is still running` indefinitely and did
  not deliver the completed turns before that command.
- Claude Code writes its own caveat record directly before a command that runs
  in the app and is not sent to the model. A tail made only of such commands,
  their printed output and the summary a compaction leaves is now complete.
  The saved history and the native file are unchanged.
- A command without that caveat expands into a prompt, so it still waits for
  its reply. So does any authored prompt or assistant output.

## Conversations that live elsewhere no longer ask for attention

- A new conversation whose working directory does not exist on this Mac cannot
  be enrolled: a Claude Desktop SSH session works in a directory on the remote
  host, and a deleted project has none. The app showed these as `New
  conversations need attention` with nothing the user could do.
- They are now listed as `absentSources` in the watcher status and do not
  change the app's state. Restoring the directory enrolls the conversation at
  the next discovery. A directory that exists but cannot be resolved is still
  reported.
