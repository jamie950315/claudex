# Claudex 1.4.8

Released on 2026-10-15. App **1.4.8** bundles Claude Mod **0.8.31**.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v1.4.8).
These notes summarize changes since 1.4.7.

## Start warming, then take a break

Send `/claudex:warm on` once in the intended conversation. You no longer need
to send an ordinary message before or after enabling it. Keep the computer awake
and the application and conversation open.

- When no usable recent request exists, Claudex sends its own initial request
  as soon as the local command finishes and the conversation is idle, then
  refreshes periodically. A fresh existing request can supply the first deadline.
- The initial request counts toward the chosen limit. A cold or expired cache
  can require a full-price read; successful requests continue the schedule even
  without a cache hit. Cache-hit reporting still uses actual native cache reads.
- The same workflow works through the Claude Mod and Codex's separately trusted
  native command hook. Codex retains its experimental best-effort limits,
  including unavailable draft visibility and per-turn no-tools enforcement.
- Changing the native configuration stops warming, including during its first
  request. Uncertain submissions are never replayed, and restarting the service
  never automatically resumes warming.

Existing Claude sessions can retain an older loaded Mod until a normal native
reload or new session. Installing the update does not restart active work.

## Completion wakes work by default

- New external root tasks default to wake notifications, with a one-hour expiry
  and blocker notifications enabled. Explicit notification choices remain intact.
- Setup and startup enable `nativeWake` and `selfWake` only when those receiver
  options have never been configured. Explicit false values, disabled plugins
  and existing delivery routes are preserved. New brokers default to `mod-self`.
  Native replies consume model allowance.
- A calling chat can bind after its native tool result has finished flushing.
  Throttled notifications stay pending, and completion delivery has reserved
  capacity instead of being lost behind other updates.
- The app reports completion-delivery readiness separately from broker and Mod
  installation. An unset native inbound policy is recognized as the native
  default; failed reads, unknown settings and explicit holds remain visible.

## Keep active work easy to find and long-running services usable

- The Mod's Tasks tab opens in **Most recent** order, shows last-update times,
  and offers **Task ID** order. API callers keep ID ordering by default.
- Settled work, chat receipts and Mod journals can be archived under capacity
  pressure while retaining exact lookup and replay evidence. Pending and
  uncertain work remains protected. Retired warm observers and invalidated cold
  proofs no longer consume capacity indefinitely.
- Permission previews and worker capabilities disclose actual sandbox, network
  and user-tool restrictions. Narrowing a requested permission is visible.
- A vanished transient Codex thread no longer pauses an unrelated conversation.
  Hook, renderer and folder-maintenance diagnostics expose their own failures
  and waiting states without disguising them as general setup failures.

## Verification

- Automated suite: 2,157 passed, 23 skipped, zero failures. The staged companion
  passed official strict validation and all 26 native Mod kit tests.
- Authorized Claude Code 2.1.295 / Sonnet 5.5 medium acceptance completed an
  autonomous initial request and a periodic request four minutes later, without
  an ordinary seed message, then stopped at the two-request limit.
- Installed Codex 0.162.0-alpha.17.2 acceptance completed one autonomous initial
  request, verified its next deadline at 25 minutes and stopped locally. The
  second request was scheduled, not awaited.
- Earlier authorized Claude Desktop acceptance verified default root completion
  wakes arriving in the originating session. Detailed version-scoped results
  are recorded in [the acceptance evidence](https://github.com/jamie950315/claudex/blob/v1.4.8/docs/agents/evidence.md).

Apple Silicon, macOS 13 or later. The app has an Apple Development signature

available on the release page.
