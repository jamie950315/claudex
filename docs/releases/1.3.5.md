# Claudex 1.3.5

Development build of 2026-10-10; not yet a published release. App **1.3.5**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged. These notes
summarize changes since 1.3.4.

## The automatic Claude restart no longer waits for a session Claude opened itself

- On the first real frontend update after 1.3.4, every adapter was written 19
  seconds after Claude Desktop started, but the one-time automatic restart was
  refused because a Code session process existed. Claude Desktop had started
  that process itself, eight seconds after launch, for the session it reopened;
  no prompt had been submitted. The restart request and its status were
  published as designed.
- A Code session process no longer prevents the automatic restart. A prompt
  submitted since Claude Desktop started still does, as do the one-minute age
  limit, the once-per-frontend and twice-in-ten-minutes limits, a declined quit
  and the disabled setting.
- A draft being typed in the composer is still not observable; text typed in
  the first minute after an update can be lost to the restart.

Checked with injected process, clock and status data. An automatic restart has
not yet been observed on a real frontend update.
