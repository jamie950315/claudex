# Claudex 1.2.41

Development build of 2026-10-10; not yet a published release. App **1.2.41**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged. These notes
summarize changes since 1.2.40.

## Normal reopening holds

- Treat an authoritative app-stop hold as a normal renderer wait, without
  recording it as a frontend failure or asking the user to resolve it.
- Keep that wait visible while the existing release notification starts guarded
  cache discovery. Only a coherent pass reports readiness; permanent refusals,
  lost notifications and independent map/history errors still need attention.
- Preserve all stop/publication fences. No lifecycle polling, native restart,
  new retry or synthetic release event is introduced.
- Localize the waiting title and explanation in all nine app languages.

Native reopening reproduced the prior misclassification: the hold was released,
and renderer verification recovered about twenty seconds later, while the old
stopped diagnostic was visible as an error. The release notification was received;
this change corrects classification during that interval.
