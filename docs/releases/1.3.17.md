# Claudex 1.3.17

Development build of 2026-10-10; not yet a published release. App **1.3.17**
bundles Claude Mod **0.8.19**. These notes summarize changes since 1.3.16.

## A conversation no longer pauses after `/compact` rewrites earlier rows

- Claude Code 2.1.295 `/compact` was observed appending a second copy of
  several hundred earlier rows (same identity, type, time and message) before
  its new boundary. Claudex read the repeated identities as ambiguous and
  paused that conversation with "Owned Claude compaction history has ambiguous
  native record identities."
- In a native Claude conversation such a copy is now ignored and the first
  record stays the history. A row that reuses an identity with different
  content still pauses, and conversations Claudex owns keep refusing every
  repeated identity. No native file is changed.

## One default warming limit for Claude and Codex

- The limit `/claudex:warm on` uses when it is given none is now saved in
  Claudex, not in Claude's plugin store, so Codex uses the same value. It is
  still four hours until changed. A value saved by 1.3.16 in the plugin store
  is not carried over.
- Saving it changes no running warm-up and enables nothing.

## Cache settings window in Claudex.app

- **Cache settings…** in the main window footer and in the menu bar menu opens
  a window with the default warming limit (1 to 168 hours, or 3 to 100
  requests), Save and Reload, and how many conversations each app is keeping
  warm now.
- Opening, reloading and choosing write nothing; only Save does.

Checked with injected data, the native validator and the native test kit. The
window was opened in the installed app; no warming inference was run for it.
