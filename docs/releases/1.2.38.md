# Claudex 1.2.38

Development build of 2026-10-09; not yet a published release. App **1.2.38**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged from App
1.2.27. App and Mod versions are separate. These notes summarize changes since
1.2.37.

## Larger frontend chunks retain finite resource bounds

- Raise the per-file cache and decoded/patched JavaScript limits from 2 MiB to
  4 MiB, using shared constants for inspection, compression and installation.
  Observed September frontend chunks reach approximately 2.37 MiB decoded.
- Preserve the graph's 256 MiB cache-byte and 2,048-module/missing-import bounds,
  original-cache journals, ownership checks and semantic anchor proofs. No extra
  owner is retained and no model work is started by this change.
- Support HTTP length-header digit changes only in the observed Chromium
  HttpResponseInfo v3 pickle layout. Preserve timestamps and the opaque native
  tail while updating string/payload/footer lengths, alignment and checksums.
  Unknown resize layouts remain refused.
- Historical vendor JavaScript is verified in reconstructed, isolated cache
  containers. Static source and installation checks do not certify historical
  native UI behavior or arbitrary future frontend semantics.
