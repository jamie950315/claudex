# Claudex 2.0.16

Released on 2026-10-23. App **2.0.16** bundles Claude Mod **0.8.74**.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v2.0.16).
App and Mod versions are separate. These notes summarize changes since the last
public release, 2.0.5 (Mod 0.8.63), including the intervening local builds.

## Preserve closed voice and interrupted image histories

- Newly enrolled Codex voice chats retain saved speaker transcripts, their order,
  native session metadata and complete API handoffs. Stable rollout evidence and
  two complete API reads establish the closed boundary; no final response is
  fabricated when the API contains only user handoffs. This fixes
  `Completed native turn lacks final response.` for these closed voice histories.
- Existing tracked voice histories retain their saved representation and
  checkpoints. The transcript policy is saved with new enrollment and survives
  restart. Open realtime sessions wait for a persisted closed boundary; original
  audio is not reconstructed.
- Interrupted Codex image turns that contain real work can synchronize even when
  their raw closing event is missing. Matching complete API reads, an error-free
  interruption, no active items and an exact completed successor must establish
  the boundary. All API items and verified images are preserved. This fixes
  `Native image turn did not close before the next native turn.` for that case.

## Keep refusals, forks and originals intact

- Import completed Claude refusals with persisted response text, preserving the
  refusal and safety notice. Tool calls in refused responses that never ran stay
  inert data; unfinished output remains an incomplete tail. Nothing is retried.
- Read Claude session metadata by conversation-chain membership rather than an
  event-type list, while retaining checkpoint-compatible older representations.
  Keep Codex skill and mention inputs whole as inert native context.
- Distinguish same-thread rollover from a logical fork parent, and read verified
  physical ancestor segments in nested Codex forks. Native image, segment,
  ordinal and byte-prefix proofs remain required.
- Preserve unchanged closed interrupted Codex originals while creating their
  continuation. Add explicit, receipt-backed selection of an edited shorter
  source before its first Claude append, only after proving the old handoff was
  never sent. This recovery is not automatic conflict resolution.

## More reliable status, shutdown and frontend integration

- Repeat the idempotent stop while Quit drains, closing owned processes that
  become idle after the first stop. Treat proven zombie native processes as
  exited without killing user work.
- Restore the ten-second status-only heartbeat during long synchronization and
  enrollment operations, including the first watcher pass. Initial verification
  stays visible until its background backlog completes.
- Follow Claude frontend metadata API and organization-header bindings when they
  move into a named shared-module import. Accept the older proven prefetch and
  metadata-reader forms without weakening cloud-access permission checks.
- Frontend monitoring checks updates and notifies on failure; it no longer
  launches Claude Code auto-repair jobs.
- Pin CLI bootstrap package integrities, improve missing-component and command
  errors, and simplify app-only installation instructions.

- The synchronization suite passed 206 tests with one ignored. Final
  enrollment-policy changes passed ten scoped tests; voice regressions passed

  216 tests in aggregate. One existing shared-source renderer test timed out in

  its app and complete bundled Mod payload match the accepted candidate.

## Install or update

Download `Claudex-v2.0.16-macOS-arm64.zip`, unzip it and place **Claudex.app**
in **Applications**. For an update, let active work finish, use **Quit Claudex**
and wait for safe shutdown before replacing the app, then reopen it. Keep your
existing private state; do not resend messages to clear a history warning.
The app manages the bundled Mod update. Open a new Claude Code session after
updating to load the new Mod; existing sessions may retain their previous version.

Apple Silicon, macOS 13 or later. This build has an **Apple Development signature
and is not notarized**. If macOS blocks the first launch, choose **Open Anyway**
in **System Settings › Privacy & Security**. The ZIP and `SHA256SUMS` are available
on the release page. No Gatekeeper bypass or native application replacement is
required.
