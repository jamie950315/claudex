# Claudex 1.3.12

Development build of 2026-10-10; not yet a published release. App **1.3.12**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged. These notes
summarize changes since 1.3.11.

## Codex cache warming no longer waits forever on Codex 0.162

- Warming waited for a native settings snapshot before it would schedule a
  refresh. Codex 0.160 sent one with every turn; 0.162 sends one only when the
  settings change, so warming stayed at `awaiting-native-settings`.
- After a model turn that Claudex observed from its start, with native usage
  and no snapshot, the settings Codex returned when Claudex rejoined the
  conversation become the baseline. The next snapshot is then a change and
  stops warming, as a changed snapshot always did.
- The turn in which warming is enabled and a turn without native usage (for
  example a prompt a hook blocked) never establish that baseline. A runtime
  that does send a snapshot keeps the full comparison.

Observed on `0.162.0-alpha.17.2`: no snapshot on two unchanged turns, one
snapshot with all fourteen validated fields when the effort was changed.
Checked with injected data; a real refresh on 0.162 is a separate acceptance.
