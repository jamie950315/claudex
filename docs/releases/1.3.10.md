# Claudex 1.3.10

Development build of 2026-10-10; not yet a published release. App **1.3.10**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged. These notes
summarize changes since 1.3.9.

## Codex cache warming works on runtimes after 0.160.0

- Codex warming accepted only native runtime `0.160.0` exactly, so every Codex
  Desktop update turned it off with `unsupported native version`.
- `0.160.0` is now the minimum. A later runtime is accepted when its thread
  settings, metadata and usage records pass the same exact validation as
  before; a changed record still stops warming with its own reason. Earlier
  runtimes and prereleases of `0.160.0` remain refused.
- The app-server schema of `0.162.0-alpha.17.2`, generated with its
  experimental fields, has the same thread-settings keys and value sets the
  validation requires.

Checked with injected data and a read-only inspection of a loaded Desktop
thread on `0.162.0-alpha.17.2`.
