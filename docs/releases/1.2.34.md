# Claudex 1.2.34

Development build of 2026-10-09; not yet a published release. App **1.2.34**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged from App
1.2.27. App and Mod versions are separate. These notes summarize changes since
1.2.33.

## Opening a conversation while another one synchronizes still reconnects it

- When a synchronized conversation's Claude owner has been closed while idle,
  opening it in Claude Desktop asks Claudex to start that owner again. The
  request was refused whenever any conversation had a delivery in progress,
  and it is not repeated, so the conversation stayed `Remote Control
  disconnected` until it was selected again. With another conversation
  actively synchronizing, that happened often.
- The request is now recorded while a delivery is in progress and handled as
  soon as that delivery finishes. A transaction that is really left pending
  still refuses the wake, as before.

An owner is still closed after 15 idle minutes, and reconnecting takes a few
seconds after it starts; the conversation shows as disconnected in between.
