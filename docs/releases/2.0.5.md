# Claudex 2.0.5

Released on 2026-10-20. App **2.0.5** bundles Claude Mod **0.8.63**.
[Release and downloads](https://github.com/jamie950315/claudex/releases/tag/v2.0.5).
App and Mod versions are separate. These notes summarize changes since 2.0.4
(Mod 0.8.62).

## Wait for the connection without blocking every conversation

- Treat a missing shared Codex transport root, backend manifest or socket during
  endpoint admission as one connection wait instead of a separate history failure
  for each scheduled conversation. Diagnostics include the failed operation and
  path rather than only `No such file or directory`.
- Preserve queued completion revisions, enrollment candidates and history checks
  until a connection or configuration event permits admission again. Status
  heartbeats do not retry admission or scan histories while disconnected.
- Revoke predecessor-handoff authority and defer folder and handoff publication
  while the connection is unavailable. Pending transaction recovery keeps its
  existing precedence.
- Keep missing histories, unsafe permissions, identity conflicts and uncertain
  native operations as explicit failures under their existing recovery rules.
  No automatic replay or alternate transport is introduced.

## Verification

- Focused core RPC/transport tests passed (12 tests). The final synchronization
  library run passed 165 tests with one ignored; work tests passed 25 unit and
  19 contract tests. All 213 host tests passed.
- Isolated watcher tests verified offline queue preservation, event-driven
  reconnection and transport-error propagation through enrollment. A missing
  history remains a conversation failure rather than a connection wait.
- Normal app-owned installation completed without restarting Codex or Claude.
  The installed watcher completed 510 conversation checks with zero blocks and
  no pending transaction. The actual app window showed synchronization ready
  and both providers connected.
- Read-only native inspection reported bundled, installed and observed loaded
  Mod 0.8.63. No model inference or uncertain message replay was used.
- The release ZIP was extracted and passed deep/strict signature verification.
  It contains the accepted signed app with App 2.0.5 and bundled Mod 0.8.63.
