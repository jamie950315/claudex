# Claudex 1.2.33

Development build of 2026-10-09; not yet a published release. App **1.2.33**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged from App
1.2.27. App and Mod versions are separate. These notes summarize changes since
1.2.32.

## Chat wake installed alone no longer blocks the shared folder resource

- When the folder adapter cannot be matched on a Claude frontend, chat wake is
  installed alone under its own journal. After 1.2.32 made the folder adapter
  match the 2026-10-09 frontend, both adapters targeted the same resource, but
  the shared installation found chat wake's patch already in the cache and
  refused: `Cache publication or recovery refused; original and journal
  preserved`. Folder placement and chat wake were both skipped.
- The installer now restores the vendor resource through the independent
  chat-wake journal first, then installs both adapters together under the
  shared journal. It does so only while that journal's own patch is exactly
  what the cache holds; the independent journal and its original are kept.
- Restoring chat wake uses whichever journal currently owns the cache.
