# Claudex 1.2.35

Development build of 2026-10-09; not yet a published release. App **1.2.35**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged from App
1.2.27. App and Mod versions are separate. These notes summarize changes since
1.2.34.

## Running /compact in a synchronized Claude conversation no longer blocks it

- A conversation that Claudex continues on the Claude side accepted a native
  compaction only in the form Claudex's own input produces. Running `/compact`
  from Claude Desktop writes a summary that was never queued input, and the
  conversation was blocked with `Owned Claude compaction lacks an exact native
  history link`.
- Claude keeps the complete earlier history in the file after such a
  compaction. Claudex now applies the proof it already uses for native
  originals: the summary hangs from the compaction boundary and any preserved
  messages are an exact chain of rows that already exist before it. The saved
  synchronized history must still match in full, and nothing is replayed.
- A summary written as queued input keeps the stricter existing rule.
