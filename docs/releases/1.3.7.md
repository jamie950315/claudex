# Claudex 1.3.7

Development build of 2026-10-10; not yet a published release. App **1.3.7**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged. These notes
summarize changes since 1.3.6.

## Restart labels end when Claude has restarted

- A live rehearsal on Claude Desktop (one adapter restored to the vendor file
  twelve seconds after launch) confirmed the automatic restart: Claudex wrote
  the file again, asked Claude to quit and reopened it within about a second,
  and the adapters loaded in the new process. The saved request appeared and
  was cleared as designed.
- The rehearsal showed one stale label: the rewritten adapter stayed
  `restart-required` in `renderer-adapters-status.json` after the restart,
  because a restart changes no frontend file and no pass followed. The label is
  now replaced as soon as the automatic restart is made, and after a restart
  made by hand at Claude's next cache write of any kind.
- Nothing in the cache is inspected for this, and it never counts as a write.

The rehearsal exercised one file, not a vendor update with late chunks. Checked
otherwise with injected data.
