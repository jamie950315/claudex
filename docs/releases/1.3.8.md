# Claudex 1.3.8

Development build of 2026-10-10; not yet a published release. App **1.3.8**
bundles Claude Mod **0.8.15**. The bundled Mod payload is unchanged. These notes
summarize changes since 1.3.7.

## A frontend may use both automatic restarts

- The automatic Claude restart was limited to once per frontend. That limit is
  removed: each restart answers one write and Claude Desktop must be newly
  started, so the existing limit of two restarts in ten minutes already ends
  any loop. A file of the same frontend that arrives after the first restart is
  now loaded by a second one instead of a request to restart by hand.
- A declined quit, or a quit whose outcome was never recorded, still ends
  automatic restarts for that frontend.

## The `/claudex` command adapter writes a load line

- The command catalogue module now logs `[Claudex commands] loaded <asset>`
  when Claude evaluates it, like the other three adapters. Whether it is active
  can be read from the renderer log instead of typing `/claudex`. The line is
  contained like every injected statement and changes nothing the user sees.
- Each installed command adapter is rewritten once to add it, which counts as a
  write: Claude needs one restart to load it.

Checked with injected data and the synthetic frontends.
