# Claudex 1.3.21

Development build of 2026-10-11; not yet a published release. App **1.3.21**
bundles Claude Mod **0.8.22** (unchanged). These notes summarize changes since
1.3.20.

## An empty Codex turn is accepted wherever it was submitted from

- Codex records a trigger for each turn: the composer, the queue, an edited
  message, the iOS remote, a goal and others. 1.3.20 accepted an empty turn
  from the composer and the iOS remote only, so a locally blocked prompt from
  any other place would still pause its conversation.
- The trigger is no longer compared. It names where a turn was submitted and
  says nothing about its content; what makes a turn empty is unchanged: no
  reply, tool or token record between its start and its completion, and
  identities and times that match what Codex reports.
- The agent-initiated form is accepted too: a parent turn, an agent path and
  another turn as the root, which the turn's context and completion must
  repeat. In 1,560 local rollouts this form appeared only in subagent
  threads, which Claudex does not synchronize, and never as an empty turn, so
  this part is checked with synthetic data only.
- Mixed or malformed forms and unknown attribution fields are still refused.
