# App icon

`AppIcon.png` is the approved original raster artwork generated with the built-in
image generation tool. Preserve the original alpha channel. The packaging tool
derives the macOS iconset and `Claudex.icns`; generated iconsets need not be committed.
This artwork is separate from the monochrome SF Symbol used in the menu bar.

## Generation prompt

Use case: logo-brand. Asset type: a single polished macOS application icon for
Claudex, a local bridge for bidirectional collaboration and handoff between two
coding assistants. Create one centered, front-facing, square 1024x1024 icon, not
a mockup or presentation sheet. A softly rounded-square graphite-black tile,
with generous consistent corner radius and subtle premium satin surface.
Inside, a bold original mark made from exactly two broad ivory/silver folded
ribbon arrows flowing in opposite directions and interlocking into a compact
unified open loop, suggesting two peers exchanging work. Clean architectural
geometry and clear negative space, strong simple silhouette legible at 32px,
restrained shallow dimensional relief, subtle soft highlights and ambient
shading, elegant native macOS feel. Mark occupies about 62% of tile width. Tile
occupies about 86% of canvas with equal padding. Transparent canvas outside
tile; rounded corners remain truly transparent. No words, no letters, no
numbers, no border captions, no watermark, no official OpenAI or Anthropic
logos, no extra decorative objects, no background scene, no neon, no rainbow
gradients, no extraneous sparkles. Deliver only the finished icon.
